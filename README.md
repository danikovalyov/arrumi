# Arrumi

A small companion for your Mac. Keep ideas, organize collections and take time to focus, with a pet by your side.

## Download

[Download Arrumi beta](https://github.com/danikovalyov/arrumi-downloads/releases)

**Requirements:** Apple Silicon (M1 or newer), macOS 13 or newer.

This is an early testing build. It is not Developer ID signed or notarized, and macOS may block it from opening. The source code is maintained in a separate private repository.

## What it includes

- Eighteen dog and cat breeds.
- Notes, clickable links, checklists and collections.
- Focus sessions and a countdown beside your pet.
- Adjustable size, opacity, screen edge and interface color.
- Spanish and English. Notes and settings are stored locally.

## Install

Unzip the download and move `Arrumi.app` to Applications. Do not replace an existing version without keeping a copy.

For issues, include your macOS version and Mac processor. Avoid attaching private notes or personal links.
